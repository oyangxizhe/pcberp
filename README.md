# 印刷线路板ERP财务软件库存贸易生产企业管理系统


#  开发背景
本ERP软件为苏州某PCB印刷电路板公司定制软件，已使用10余年并已在多家同行业中使用。


#  功能描述
本ERP软件为昆山PCB印刷电路板公司定制软件，已使用10余年并已在多家同行业中使用。
功能上软件分九个模块，分别为
基础资料、
采购管理、
销售管理、
库存管理、
品质管理、
用户管理、
属性管理、
财务管理、
追溯系统
实现从
建立品号信息-产生报价-
录入客户订单-采购物料-
入库退货-采购对账-
库存查询-销货销退-
客户对账-供应商请款付款-
客户收款-汇总统计报表-产品追溯
完成一个电子化系统作业流程，方便企业对所需各种数据查询统计，实现企业管理透明清晰，账目清楚，提高生成效率的目的，其中报价功能是本软件的特色功能。
